# TaskTie

**Every task, tied to a vendor.** TaskTie is a vendor checklist for solo wedding planners. It shows who's doing what and when on the wedding day, and flags any task that no vendor claimed, that two vendors claimed, or that has a time conflict.

## Live pages
- **Website:** https://hannahcaruso.github.io/TaskTie/website/
- **App:** https://hannahcaruso.github.io/TaskTie/app/ (click **Load demo weddings** to try it)
